# Elderly Support Website

A responsive multi-section charity website prepared as a static HTML/CSS/JavaScript project.

## Project structure

- `index.html` — page structure and all website sections
- `css/style.css` — shared styling, responsive layouts, and animations
- `js/script.js` — mobile menu, scroll reveals, impact counters, and footer year
- `images/` — place the referenced image files here

## Setup

1. Copy the project files into your GitHub repository.
2. Add your images to the `images` folder using the exact filenames referenced in `index.html` and `css/style.css`.
3. Replace `Your Charity Name`, the contact placeholders, and the social media `href="#"` values with your real details.
4. Update the impact counters in `index.html` only with verified figures.
5. Open `index.html` in a browser to preview the page.

## GitHub Pages note

The navigation currently uses root-relative paths such as `/about` and `/donate`, as in the supplied section code. If the site is published from a GitHub Pages project repository (for example, `username.github.io/repository-name/`), these routes may point to the domain root instead of the project folder. Adjust the paths or implement matching pages/routing before publishing.
